# 原理图核对清单（11-08 缓冲日）

> **为什么今天做这件事**：`_setup/README.md` 里那张引脚表只回答了「哪个功能在哪个脚」，
> 但代码要写对，还需要另一半信息 —— **电气条件**：高电平亮还是低电平亮、按下是高还是低、
> 有没有硬件消抖、上电瞬间是什么电平。这些只能从原理图上看出来。

## 读原理图的顺序（别一上来就找 LED）

按供电的方向读，一层一层往下：

```
① 电源与地 → ② 复位与时钟 → ③ 下载口 → ④ 外设（LED / 按键 / 串口）→ ⑤ 排针
```

先看电源，是因为**所有「上电瞬间电平」的问题都出在这一层**；先看下载口，是因为**它被占用的话，
后面所有代码都烧不进去**。LED 是最不重要的一层，却总是被最先翻到。

## 核对表

填「结论」列的时候写实际值，不要写「正常」。**「正常」等于没看。**

### ① 电源与地

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| 供电来源 | 5V 从 USB 还是 DC 座进来，有没有 LDO（如 AMS1117-3.3） | 板上有 3.3V 稳压，MCU 供 3.3V | |
| 去耦电容 | 每个 VDD 脚附近有没有 100nF，VDDA 有没有磁珠 + 10uF | 缺了会在 ADC / 高频下出怪问题 | |
| 地平面 | 模拟地 / 数字地是否分开，单点连接 | 影响 ADC 噪声，本周不用但先记下 | |

### ② 复位与时钟

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| NRST 电路 | 10k 上拉到 3.3V + 100nF 到地（低电平复位） | 有复位按键则按键接地 | |
| 复位按键 | `SW2` 是否直连 NRST | 引脚表里记的是 `SW2 → NRST`，核对丝印 | |
| HSE 晶振 | 8MHz 还是别的值，负载电容多大（常见 20pF） | F103 最高 72MHz，8MHz × 9 = 72 | |
| LSE 晶振 | 有没有 32.768kHz（RTC 用） | 没有就在代码里别开 LSE | |

### ③ 下载口（这条最优先，搞错就全盘停摆）

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| SWD 引脚 | PA13(SWDIO) / PA14(SWCLK) 有没有被 LED、按键、排针同时占用 | 被占用会导致连不上或功能冲突 | |
| 是否引出 NRST | 4 针是 `3V3/GND/SWDIO/SWCLK` 还是带 NRST 的 5 针 | 带 NRST 才能「连接时复位」 | |
| BOOT0 | 有没有 10k 下拉到地；跳线帽默认接哪边 | 下拉 = 从 Flash 启动（正常运行时必须这样） | |
| BOOT1 | 是否接地 | BOOT0=1 且 BOOT1=0 才进 ISP | |

### ④ 外设：LED

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| 接法 | LED 阳极接 3.3V、阴极经电阻到 GPIO（**共阳，低电平亮**）还是反过来 | 决定代码里 `GPIO_ResetBits` 是点亮还是熄灭 | |
| 限流电阻 | 阻值多少（常见 510Ω / 1kΩ） | 3.3V - 2.0V(红光) ≈ 1.3V，1kΩ → 1.3mA | |
| 灌电流余量 | 单脚 ≤ 25mA、全部 IO 合计 ≤ 150mA（F103 绝对最大值） | 三个 LED 各 1~3mA，远低于上限 | |
| 上电默认 | 复位后 GPIO 是**浮空输入**，此时 LED 会不会微亮 | 微亮是正常的，不是漏电 | |

### ⑤ 外设：按键（11-10 消抖要用）

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| 上/下拉 | PF8/PF9 有下拉电阻（10k 到地）→ 按下为**高**；PF10/PF11 有上拉 → 按下为**低** | 决定代码里配 `GPIO_PULLDOWN` 还是 `GPIO_PULLUP` | |
| 是板载还是内部 | 电阻是画在原理图上的实体，还是靠 MCU 内部上拉 | 板载了就不用开内部上下拉（开了也不会坏，只是多耗电） | |
| 硬件消抖 | 按键两端有没有并联 100nF 电容 | 有电容可以把软件消抖窗口缩短 | |
| 串联电阻 | 有没有 100Ω~1kΩ 串在按键与 GPIO 之间 | 防静电/短路保护 | |

### ⑥ 外设：串口

| 项目 | 在原理图上找什么 | 预期 / 判据 | 结论 |
|---|---|---|---|
| TX/RX 交叉 | MCU 的 PA9(TX) 接 CH340 的 RXD，PA10(RX) 接 CH340 的 TXD | **同名相连是错的**，必须交叉 | |
| CH340 供电 | 3.3V 还是 5V；5V 供电时它的 TXD 输出是 5V | 5V 输出直连 MCU 会超压（见下一节 FT） | |
| 一键下载电路 | DTR/RTS 是否经三极管控制 BOOT0 与 NRST | 有的话串口工具能自动进 ISP | |

### ⑦ 5V 容忍（接外部模块前的必查项）

F103 的 IO **大部分**标 FT（5V tolerant），但**不是全部**。以下这几脚在数据手册 pin definition
表里没有 FT 标注，接 5V 器件前必须确认：

```
PA13 / PA14 / PA15 / PB3 / PB4     ← 前两个正是 SWD
```

判据只有一条：**翻数据手册的 pin definition 表，看那一位是不是 FT**。原理图上看到 5V 器件
直连某个 IO 时，回来查这一条。

## 没有原理图怎么办

手上只有板子、没有 PDF 的话，用两个工具反查，结论一样可靠：

**万用表（断电，蜂鸣档）**

- 测 LED：红笔点 3.3V、黑笔点 GPIO 焊盘，响 → 共阳低电平亮
- 测按键：不按时应不通，按下导通；一边必接地或 3.3V，**由此判断按下是高还是低**
- 测上/下拉：按键两端之间量到 10k 左右 → 有实体电阻

**万用表（上电，直流电压档）**

- 空程序运行时量每个 IO 对地电压：接近 0V 或 3.3V 说明有外部上下拉；飘在 1~2V 说明浮空
- 这条能直接回答「复位后这个脚是什么电平」，比看原理图还准
