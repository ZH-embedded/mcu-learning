- 任务：指针基础 6 题 —— 地址与解引用、指针版 swap、指针遍历数组、二级指针、`int *p[3]` vs `int (*p)[3]`、4 个真实指针 bug
- 做了什么：`01-c/w1-pointer/` 六个文件的函数体全部自己写，`./build_run.sh` 编译零警告，**70 条断言全过**（6 / 8 / 21 / 15 / 11 / 9）；当天硬产出拿下：`int *p[3]` 占 24、`int (*p)[3]` 占 8、`sizeof(*p)` 才是 12，能当面讲清为什么
- 卡点：
  - p03 `reverse_inplace` 写成 `for (; left < right;)` 却从头到尾没动过 `left`/`right` → 死循环；第三行还抄成 `*right = *(left + i)`，变量根本不对。修：改 `while`，`*right = temp`。附带一点：`int *right = arr + n - 1` 在 `n == 0` 时算出的是 `arr - 1`，指针跑到数组外面本身就是 UB，所以 `n <= 0` 必须先 return
  - p04 `point_to` 只写了 `idx >= n` 挡上界，`-1 >= 4` 是假，负数一路越界读。修成 `if ((unsigned)idx >= (unsigned)n)` —— 一次同时挡负数和越界，比写两个判断干净
  - p06 `fill_ok` 是 `void` 函数，从上一题 `get_safe`（返回 `int *`）整段抄了个 `return NULL;`，`-pedantic-errors` 下直接 error。修：`return;`
  - p05 留了个幽灵 `int j = 0;`（从 C89 风格的 `sum_matrix` 抄来的），被内层 `for (int j = 0; ...)` 遮蔽，编译不报错，但读的人要愣一下
  - p05 三题非法输入返回 `-1`，可矩阵和本身就能被负数污染，"出错了"和"和恰好是 -1"分不开。修：统一返回 0
  - 值传递版 `swap_by_value` 在 `-O2` 下被整段删成一条 `ret`（形参没人用），拿它证明"改不到外面"得看反汇编，光看打印是看不出来的
  - 记一下走弯路的成本：`./build_run.sh > 运行结果.txt` 是多余的重定向，脚本自己就写 `运行结果.txt`，两路同时写同一个文件会把内容打洞
- 学到：`arr[i] ≡ *(arr + i)`，所以 p03 那三种遍历写法其实是一种；数组名不是可修改的左值，`arr++` 编译就错，要动先 `int *p = arr`；数组形参在函数里退化成指针，`sizeof(arr)/sizeof(arr[0])` 桌面得 2（8/4）、板子得 1（4/4），**长度只能单独传一个参数**；`&` 和 `sizeof` 是仅有的两个不触发数组退化的操作符（`&arr` 得 `int (*)[N]`）；二级指针的唯一用途是改调用者的指针变量，12 月链表删头节点就是 `Node **head`
- 今天最值钱的一条：**最大的坑不是语法，是抄结构**。`return NULL`、幽灵 `j`、没用到的 `arr`，全是把上一个函数整段搬过来没删干净。以后写完一个函数先扫一遍"这几个变量和返回值真的用得上吗"，再编译
