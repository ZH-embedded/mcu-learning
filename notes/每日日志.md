- 学到：
  - 函数指针本身就是地址：`f(a,b)` 和 `(*f)(a,b)` 完全等价；函数名不是函数指针，但一进表达式就退化成 `&f`（`_Generic` 实测 `&f` 的类型是 `int *(*)(int,int)`）
  - `typedef` 的别名站在"变量名原本的位置"，不一定在行尾。`typedef int (*binop_t)(int,int);` 里 `binop_t` 夹在中间，因为后面还有 `(int,int)` 在描述它；把 `typedef` 三个字母删掉，剩下就是一条合法变量声明，`binop_t` 当变量用能赋值、能调用
  - **空格不影响语义，括号才影响**：`int *f(int,int)` 和 `int* f(int,int)` 都是"返回 `int *` 的函数"，类型一字不差；但 `int* f, g;` 里 `g` 是 `int`，因为星号只修饰紧跟它的那一个名字
  - `const` 在星号左边是**给调用者的合同**（`const int *p`：我不改你的数据），在星号右边是**给自己的备注**（`int *const p`：我不改自己的指向）。后者调用者看不见，也不进函数签名，所以真实代码里少见
  - 回调 + `void *ctx` 替代全局变量：可重入、一个回调能服务多个累加器、单元测试之间不互相污染——POSIX `pthread_create` 和 FreeRTOS `xTaskCreate` 里那个 `void *` 就是这个意思
  - 比较器不写 `a - b`，写 `(a > b) - (a < b)`：实测 `qsort` 用 `a-b` 版排 `{INT_MIN, 1, -1, 5, 0}`，结果把 `INT_MIN` 排到了中间，而程序不崩、不警告，只是结果错
  - 注册表模式：加一条命令 = 表里加一行，查找 / 执行 / 帮助全部自动跟上，不用改三个地方
- 今天最值钱的一条：**测试全绿不等于代码正确**。p05 第一版 27/27 通过，可表里只要多一行占位行，后面命令全部静默失效；`run_command` 那版 27/27 也过，可打错命令直接段错误——因为我给的测试表里既没有占位行，也没有 `handler == NULL`。**通过的是别人给的测试，不是"正确"**；交活之前自己问一句"还有什么输入是我没喂过的"
