  char arr[]   = "abc"  sizeof =  4   strlen = 3
  char *ptr    = "abc"  sizeof =  8   strlen = 3
  char buf[32] = "abc"  sizeof = 32   strlen = 3

  看懂这三行，就明白为什么函数里必须用 strlen 而不是 sizeof。

结果: 3 通过, 0 失败

=== 为什么返回 dst（链式调用）===
  my_strcpy(a, "hello") = "hello"
  可以连着用：my_strcpy(b, my_strcpy(a, "hi")) → b = "hi"

一个真实教训：strcpy 不知道 dst 有多大，
  别人传进来的 src 比你缓冲区长，就静默踩坏后面的内存，
  程序不报错、继续跑，直到某个不相关的变量莫名其妙变值。
  → 所以实际工程里要么用 strncpy(dst, src, sizeof(dst)-1)，
    要么自己写一个带 size 参数的版本。

  [PASS] "abc" vs "abd"             → -1
  [PASS] "abd" vs "abc"             → 1
  [PASS] "abc" vs "abcd"            → -1
  [PASS] "abcd" vs "abc"            → 1
  [PASS] "" vs ""                   → 0
  [PASS] "" vs "a"                  → -1
  [PASS] "A" vs "a"                 → -1
  [PASS] "Z" vs "a"                 → -1

结果: 9 通过, 0 失败

=== 三个值得记的结论 ===
  1. 大小写敏感："Z" < "a"，因为比的是 ASCII 码不是字母表顺序
  2. 短串不一定小："abc" vs "abcd" 前面全一样，比到 '\0' 才分出大小
  3. 返回值别当数字用：标准只说符号，实现可以返回-1/1，也可以返回字符差值
